# RotulaAI

Aplicativo inteligente para criação de conceitos de rótulos e embalagens utilizando Inteligência Artificial.

## 🚀 Objetivo

O RotulaAI ajuda pequenos empreendedores a criarem conceitos de rótulos e embalagens utilizando Inteligência Artificial.

O aplicativo gera:

- Conceito criativo
- Paleta de cores
- Direção de arte
- Tipografia sugerida
- Prévia visual
- Captação de leads para desenvolvimento profissional

## 🛠 Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- Firebase
- OpenAI
